## 4.1 应用层入口（src/）

应用层是各兵种的 `main()` 函数，负责组装模块、运行主循环。每个入口对应一种兵种 + 一种工作模式。

### 4.1.1 sentry.cpp — 哨兵主程序（当前主要入口）

**依赖：** auto_aim + omniperception + io(Gimbal+Camera+ROS2) + tools

**初始化序列：**
```
Exiter → ROS2(config) → Gimbal(serial) → Camera(hikrobot)
      → YOLO(config) → Solver(config) → Tracker(config+Solver)
      → Planner(config) → Decider(config)
```

**主循环流程：**
```
while (!exiter.exit()):
  1. camera.read(img, timestamp)           -- 获取图像+时间戳
  2. q = gimbal.q(timestamp)               -- 串口获取四元数（SLERP 插值）
  3. gs = gimbal.state()                   -- 获取云台状态
  4. solver.set_R_gimbal2world(q)          -- 设置旋转矩阵
  5. armors = yolo.detect(img)             -- YOLO 检测装甲板
  6. decider.get_invincible_armor(...)     -- 更新无敌状态
  7. decider.armor_filter(armors)          -- 过滤无敌敌人
  8. decider.set_priority(armors)          -- 设置目标优先级
  9. targets = tracker.track(armors, t)    -- EKF 跟踪
  10. if tracker_lost:                     -- 目标丢失
        gimbal.send(0)                     --   停止控制
      else:
        plan = planner.plan(target, speed) --   MPC 轨迹规划
        gimbal.send(plan)                  --   发送控制指令
  11. ros2.publish(vision_target_state)    -- ROS2 发布融合状态
```

**退出时：** 发送零指令停止云台。

### 4.1.2 standard_mpc.cpp — 步兵 MPC 版

**依赖：** auto_aim + auto_buff + io(Gimbal+Camera) + tools

**架构特点：双线程**
- **主线程：** 图像采集 → YOLO 检测 → Tracker 跟踪 → 推入 target_queue
- **plan_thread：** 从 target_queue 取目标 → Planner 规划 → Gimbal 发送 → Plotter 绘图

**模式切换：** 根据 `gimbal.mode()` 在 AUTO_AIM / SMALL_BUFF / BIG_BUFF / IDLE 间切换。

### 4.1.3 standard.cpp — 步兵旧版

**特点：** 使用 CBoard（CAN 总线）通信 + Aimer 传统决策器。是最早实现完整自瞄流程的入口。

## 4.2 自瞄模块（tasks/auto_aim/）

自瞄模块是整个项目的核心 pipeline，从图像输入到控制指令输出。

### 4.2.1 YOLO 检测器

**文件：** `yolo.hpp` / `yolos/yolov5.cpp` / `yolos/yolov8.cpp` / `yolos/yolo11.cpp`

**设计模式：** 策略模式

```
YOLO (外观类)
 └── YOLOBase* (接口)
      ├── YOLOv5 : YOLOBase
      ├── YOLOv8 : YOLOBase
      └── YOLO11 : YOLOBase
```

**YOLO 类接口：**
```cpp
class YOLO {
  YOLO(const std::string & config_path, bool debug = true);
  std::list<Armor> detect(const cv::Mat & img, int frame_count = -1);
};
```

**YOLO11 推理流程（以 yolo11.cpp 为例）：**
1. **预处理：** Letterbox 缩放到模型输入尺寸，归一化
2. **推理：** OpenVINO `compiled_model.infer()` 同步推理
3. **后处理：**
   - 解析输出张量（38 类，每类 4 关键点 + 置信度）
   - 置信度过滤（`score_threshold_ = 0.7`）
   - NMS（`nms_threshold_ = 0.3`）
   - 关键点排序（`sort_keypoints`）
   - 构建 `Armor` 对象
4. **可选：** 使用 Detector 做二次验证（`use_traditional`）

**模型选择：** 由配置文件 `yolo_name` 字段决定（"yolov5" / "yolov8" / "yolo11"）。

### 4.2.2 传统检测器（Detector）

**文件：** `detector.hpp` / `detector.cpp`

**流程：**
1. 颜色分割 → 灯条候选（颜色、长宽比、角度约束）
2. 灯条配对 → 装甲板候选（距离、角度、矩形度约束）
3. PCA 角点回归（`lightbar_points_corrector`）
4. TinyResNet 分类（`Classifier`）
5. 类型判定（大/小装甲板）

```cpp
enum Color       { red, blue, extinguish, purple };
enum ArmorType   { big, small };
```

### 4.2.4 位姿解算器（Solver）

**文件：** `solver.hpp` / `solver.cpp`

**核心职责：**

| 方法 | 功能 |
|------|------|
| `set_R_gimbal2world(q)` | 通过 IMU 四元数更新云台→世界旋转矩阵 |
| `solve(Armor&)` | PnP 解算装甲板在云台坐标系下的 3D 位置 |
| `optimize_yaw(Armor&)` | yaw 角迭代优化（最小化重投影误差） |
| `reproject_armor(...)` | 3D 装甲板重投影回像素坐标 |
| `world2pixel(...)` | 世界坐标→像素坐标 |

**坐标变换链：**
```
像素坐标 (u,v)
  ↓ camera_matrix + distort_coeffs（去畸变 + 内参逆）
相机坐标系
  ↓ R_camera2gimbal, t_camera2gimbal（手眼标定外参）
云台坐标系
  ↓ R_gimbal2world（IMU 四元数实时更新）
世界坐标系
```

**yaw 优化算法：**
- PnP 初始解给出 yaw 粗值
- 遍历 yaw 搜索空间，最小化 4 个关键点的重投影误差之和
- 使用 `SJTU_cost` 作为代价函数（加权重投影误差）

### 4.2.5 目标跟踪器（Tracker）

**文件：** `tracker.hpp` / `tracker.cpp`

**状态机：**
```
lost ──── 检测到目标 ────> detecting
  ↑                         │
  │ 连续丢失 > max_temp     │ 连续检测 ≥ min_detect_count
  │ _lost_count             │
  └─────────────────────────┘
                            │
                            ▼
                       tracking
                            │
                            │ 连续丢失 > max_temp_lost_count
                            ▼
                          lost
```

**EKF 状态向量（10 维）：**
```
[x, vx, y, vy, z, vz, yaw, yaw_rate, r1, r2]
  ─位置3D─  ─速度3D─  ─yaw─  ─角速度─  ─两板半径─
```

**跟踪逻辑 `track(armors, t)`：**
1. **预测：** `target_.predict(dt)` — EKF 状态预测
2. **匹配：** 计算每个检测装甲板与目标的重投影误差，选最小者
3. **更新：** `target_.update(armor)` — EKF 观测更新
4. **切板检测：** 通过 yaw 角跳变判断小陀螺装甲板切换，更新 `armor_id_offset_`
5. **发散检测：** 状态发散时重置跟踪器

### 4.2.6 目标状态（Target）

**文件：** `target.hpp` / `target.cpp`

**核心接口：**
```cpp
class Target {
  void predict(std::chrono::steady_clock::time_point t);  // 预测到指定时刻
  void predict(double dt);                                  // 按时间增量预测
  void update(const Armor & armor);                         // EKF 观测更新
  Eigen::VectorXd ekf_x() const;                           // 获取 EKF 状态
  std::vector<Eigen::Vector4d> armor_xyza_list() const;    // 计算各装甲板位置
  double armor_z_offset(int id) const;                     // 装甲板高度偏移
  int physical_armor_id(int id) const;                     // 物理装甲板编号
  bool fixed_center_rotation_model() const;                // 是否使用固定中心旋转模型
  bool diverged() const;                                    // 是否发散
  bool convergened();                                       // 是否收敛
};
```

**`armor_xyza_list()` 计算逻辑：**
- 根据 EKF 状态（旋转中心位置、半径、yaw、装甲板数量和高度偏移）
- 计算每个装甲板的 3D 位置 [x, y, z, angle]
- 支持固定中心旋转模型（前哨站）和普通旋转模型

### 4.2.7 轨迹规划器（Planner）★ 核心创新

**文件：** `planner/planner.hpp` / `planner/planner.cpp`

**常量：**
```cpp
constexpr double DT = 0.01;          // 规划步长 10ms
constexpr int HALF_HORIZON = 50;     // 半视界 50 步
constexpr int HORIZON = 100;         // 全视界 100 步（1 秒）
using Trajectory = Eigen::Matrix<double, 4, HORIZON>;  // [yaw, yaw_vel, pitch, pitch_vel]
```

**输出结构：**
```cpp
struct Plan {
  bool control;        // 是否控制云台
  bool fire;           // 是否开火
  float target_yaw;    // 目标 yaw
  float target_pitch;  // 目标 pitch
  float yaw;           // 规划 yaw（MPC 输出）
  float yaw_vel;       // 规划 yaw 速度（前馈）
  float yaw_acc;       // 规划 yaw 加速度（前馈）
  float pitch;         // 规划 pitch
  float pitch_vel;     // 规划 pitch 速度
  float pitch_acc;     // 规划 pitch 加速度
};
```

**核心算法流程 `plan(target, bullet_speed)`：**

**Step 0 — 子弹速度检查：**
```cpp
if (bullet_speed < 10 || bullet_speed > 25) bullet_speed = 22;
```

**Step 1 — 命中时刻迭代 `solve_hit_target()`：**
```
for iter in 0..6:
  1. iter_target = base_target
  2. iter_target.predict(fly_time)          -- 预测到命中时刻
  3. selection = choose_aim_selection(...)   -- 选板
  4. xyz = resolve_aim_xyz(target, selection)-- 计算瞄准点
  5. bullet_traj = Trajectory(v0, d, h)     -- 弹道解算
  6. if |new_fly_time - old_fly_time| < tol -- 收敛？
       → 返回 solution
  7. fly_time = new_fly_time                -- 更新飞行时间
```

**Step 2 — 生成参考轨迹 `get_trajectory()`：**
```
target.predict(-DT * 51)                    -- 回退到视界起点
for i in 0..100:
  target.predict(DT)                        -- 每步推进 10ms
  yaw_pitch = solve_aim_command(target)     -- 计算瞄准角度
  traj[0,i] = yaw - yaw0                   -- yaw 相对值
  traj[1,i] = yaw_vel                      -- yaw 速度（中心差分）
  traj[2,i] = pitch                         -- pitch 绝对值
  traj[3,i] = pitch_vel                     -- pitch 速度
```

**Step 3 — TinyMPC 求解 yaw 轴：**
```
状态: x = [yaw, yaw_vel]
控制: u = [yaw_acc]
模型: x(k+1) = A*x(k) + B*u(k), A = [[1,DT],[0,1]], B = [[0],[DT]]
代价: sum(Q * x^2 + R * u^2)
约束: |u| <= max_yaw_acc
tiny_solve(yaw_solver_)                     -- ADMM 求解，< 1ms
```

**Step 4 — TinyMPC 求解 pitch 轴：** 同上。

**Step 5 — 开火决策：**
```
tracking_error = hypot(yaw_err, pitch_err)  -- 规划轨迹与射击轨迹偏差
fire_ready = tracking_error < fire_thresh   -- 偏差小于阈值
if outpost:
  fire_ready &= hit_converged               -- 命中迭代收敛
  fire_ready &= |delta_angle| <= fire_phase -- 在可射击角度窗口内
```

**选板策略 `choose_aim_selection()`：**

| 场景 | 策略 |
|------|------|
| 目标未发生过切板 | 选当前观测板，不切换 |
| 非小陀螺（角速度 < 2 rad/s） | 选最近可见板，带锁板防抖 |
| 小陀螺（角速度 >= 2 rad/s） | 优先选正在进入可射击窗口的板（"spin gate"） |
| 前哨站 | 独立的 coming/leaving 角度窗口 |

**TinyMPC 配置参数：**
- yaw 轴：Q=[3e6, 0.3], R=[1.57], max_acc=90°/s²
- pitch 轴：Q=[7e5, 0], R=[1.0], max_acc=75°/s²
- max_iter = 10

### 4.5.2 云台通信（Gimbal）

**文件：** `gimbal/gimbal.hpp` / `gimbal/gimbal.cpp`

**通信协议：** 串口（MicroUSB 虚拟串口）

**数据结构（packed，≤ 64 bytes）：**
```cpp
struct GimbalToVision {          // 下位机 → 视觉
  uint8_t head = 0x5A;          // 帧头
  uint8_t mode;                 // 0:idle 1:auto_aim 2:small_buff 3:big_buff
  float q[4];                   // 四元数 (w,x,y,z)
  float yaw, yaw_vel;           // yaw 角 + 角速度
  float pitch, pitch_vel;       // pitch 角 + 角速度
  float bullet_speed;           // 子弹速度
  uint16_t bullet_count;        // 子弹计数
  uint16_t crc16;               // CRC16 校验
};

struct VisionToGimbal {          // 视觉 → 下位机
  uint8_t head = 0xA5;          // 帧头
  uint8_t mode;                 // 0:不控制 1:控不开火 2:控+开火
  float yaw, yaw_vel, yaw_acc;  // yaw 目标 + 速度前馈 + 加速度前馈
  float pitch, pitch_vel, pitch_acc;  // pitch 同上
  uint16_t crc16;
};
```

**四元数插值 `q(timestamp)`：**
```
循环：
  pop(q_a, t_a)   ← 队列最早数据
  front(q_b, t_b) ← 队列最新数据
  k = (t - t_a) / (t_b - t_a)
  q_c = q_a.slerp(k, q_b).normalized()
  if t_a < t <= t_b: return q_c
```

**读取线程 `read_thread()`：**
```
while (!quit_):
  1. 帧同步：逐字节读取直到 0x5A
  2. 读取剩余数据
  3. CRC16 校验
  4. 提取四元数 → push 到 queue_
  5. 更新 state_（yaw/pitch/速度/子弹）
  6. 更新 mode_
  7. 连续 5000 次错误 → reconnect()
```

## 4.6 工具层（tools/）

### 4.6.1 扩展卡尔曼滤波器（ExtendedKalmanFilter）

**文件：** `extended_kalman_filter.hpp` / `extended_kalman_filter.cpp`

**通用 EKF 实现，支持自定义函数：**
```cpp
class ExtendedKalmanFilter {
  Eigen::VectorXd x;  // 状态向量
  Eigen::MatrixXd P;  // 协方差矩阵

  // 状态加法函数（处理角度环绕等非线性）
  std::function<VectorXd(const VectorXd&, const VectorXd&)> x_add;

  // 预测
  VectorXd predict(const MatrixXd & F, const MatrixXd & Q);
  VectorXd predict(const MatrixXd & F, const MatrixXd & Q,
                   std::function<VectorXd(const VectorXd&)> f);

  // 更新
  VectorXd update(const VectorXd & z, const MatrixXd & H, const MatrixXd & R);
  VectorXd update(const VectorXd & z, const MatrixXd & H, const MatrixXd & R,
                  std::function<VectorXd(const VectorXd&)> h, ...);
};
```

**内置统计：** NEES/NIS 卡方检验数据、滑动窗口失败计数。

### 4.6.2 弹道解算（Trajectory）

**文件：** `trajectory.hpp` / `trajectory.cpp`

**模型：** 无空气阻力抛物线弹道。

```cpp
struct Trajectory {
  bool unsolvable;  // 是否无解
  double fly_time;  // 飞行时间 (s)
  double pitch;     // 俯仰角 (rad，抬头为正)

  Trajectory(double v0, double d, double h);
  // v0: 子弹初速度 (m/s)
  // d:  水平距离 (m)
  // h:  竖直高度差 (m)
};
```

**求解：** 牛顿迭代法求解抛物线方程。

### 4.6.3 运行时热调参数（RuntimeParams）

**文件：** `runtime_params.hpp` / `runtime_params.cpp`

**机制：**
```
WebDebugger 修改参数
  → runtime_params::apply(config_path, request)
  → 版本号 version++ 递增

各模块主循环:
  if runtime_params::version() != cached_version:
    → 重新读取参数
    → 重建 solver 等需要更新的对象
```

**接口：**
```cpp
namespace tools::runtime_params {
  void register_config(const std::string & config_path);
  uint64_t version(const std::string & config_path);
  double get_double(config, key);
  int get_int(config, key);
  bool get_bool(config, key);
  std::string get_string(config, key);
  std::vector<double> get_number_array(config, key);
  nlohmann::json apply(config, request, source);
  nlohmann::json reset(config, keys, source);
}
```

### 4.6.4 Web 调试器（WebDebugger）

**文件：** `web_debugger.hpp` / `web_debugger.cpp`

**架构：** 内置 HTTP 服务器，提供网页调试界面。

**能力：**
- MJPEG 视频流（主画面 + 弹道画面）
- 实时状态 JSON
- PlotJuggler 格式曲线数据
- 运行时参数修改（热调）
- 模式切换

**默认端口：** 8090

### 4.6.5 线程安全队列（ThreadSafeQueue）

**文件：** `thread_safe_queue.hpp`

```cpp
template <typename T, bool PopWhenFull = false>
class ThreadSafeQueue {
  void push(const T & value);   // 满时：PopWhenFull=true 则丢弃最旧，否则丢弃新值
  T pop();                       // 空时阻塞等待
  T front();                     // 空时阻塞等待，返回拷贝
  bool empty();
  void clear();
};
```
