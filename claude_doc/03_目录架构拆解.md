## 3.2 模块归属关系

```
src/ (应用层)
 ├── 链接 → tasks/auto_aim    (自瞄功能)
 ├── 链接 → tasks/auto_buff   (打符功能)
 ├── 链接 → tasks/omniperception (全向感知，仅哨兵)
 ├── 链接 → io               (硬件抽象)
 └── 链接 → tools            (工具库)

tasks/auto_aim
 └── 链接 → io, openvino, tinympc

tasks/auto_buff
 └── 链接 → auto_aim, openvino, ceres

tasks/omniperception
 └── 链接 → openvino

io
 └── 链接 → hikrobot_sdk, mindvision_sdk, serial, yaml-cpp, ros2(可选)
```
