## 5.2 各阶段数据详解

### 阶段 1：图像采集

```
Camera.read(img, timestamp)
```
- **输出：** `cv::Mat img` (BGR 图像) + `steady_clock::time_point timestamp`
- **帧率：** 工业相机 ~120 FPS
- **同步：** 时间戳为图像接收完成时刻

### 阶段 2：姿态获取

```
Gimbal.q(timestamp) → Eigen::Quaterniond q
Gimbal.state() → GimbalState { yaw, yaw_vel, pitch, pitch_vel, bullet_speed, bullet_count }
```
- **四元数插值：** SLERP，基于串口读取的两个最近数据点
- **延迟：** 串口传输 + 帧同步延迟

### 阶段 3：神经网络检测

```
YOLO.detect(img) → std::list<Armor>
```
- **每个 Armor 包含：**
  - 4 个顶点像素坐标 `points[4]`
  - 颜色 `color`（red/blue）
  - 类型 `type`（big/small）
  - 名称 `name`（one~five/sentry/outpost/base）
  - 置信度 `confidence`
  - 检测框 `box`
- **推理耗时：** ~5-10ms（OpenVINO CPU）

### 阶段 4：位姿解算

```
Solver.set_R_gimbal2world(q)  // 设置旋转矩阵
Solver.solve(armor)           // PnP 解算 → armor.xyz_in_gimbal
```
- **输出填充：** `xyz_in_gimbal`, `xyz_in_world`, `ypr_in_gimbal`, `ypr_in_world`
- **坐标链：** 像素 → 相机(去畸变) → 云台(PnP+外参) → 世界(IMU旋转)

### 阶段 5：目标跟踪

```
Tracker.track(armors, timestamp) → std::list<Target>
```
- **EKF 状态（10 维）：** [x, vx, y, vy, z, vz, yaw, yaw_rate, r1, r2]
- **输出每个 Target 包含：**
  - EKF 状态（位置、速度、角速度）
  - 各装甲板 3D 位置列表 `armor_xyza_list()`
  - 跟踪状态（tracking/detecting/lost）

### 阶段 6：轨迹规划

```
Planner.plan(target, bullet_speed) → Plan
```
- **内部流程：**
  1. 延迟补偿：`target.predict(delay_time)`
  2. 命中迭代：`solve_hit_target()` → fly_time, selection
  3. 轨迹生成：`get_trajectory()` → Trajectory (4×100)
  4. MPC 求解：yaw 轴 + pitch 轴
  5. 开火判断：tracking_error < fire_thresh
- **输出：** Plan { control, fire, yaw, yaw_vel, yaw_acc, pitch, pitch_vel, pitch_acc }

### 阶段 7：控制指令发送

```
Gimbal.send(control, fire, yaw, yaw_vel, yaw_acc, pitch, pitch_vel, pitch_acc)
```
- **封装：** VisionToGimbal 结构体 + CRC16
- **传输：** 串口写入

## 5.3 多线程数据流（standard_mpc.cpp）

```
┌─────────────────────────────────────────────────────────────────┐
│                         主线程                                    │
│  Camera.read → YOLO.detect → Tracker.track                      │
│       │                                                          │
│       │ target_queue.push(target)                                │
│       ▼                                                          │
│  ┌──────────────┐                                                │
│  │ target_queue  │ (ThreadSafeQueue<optional<Target>, max=1>)    │
│  │ PopWhenFull   │                                               │
│  └──────┬───────┘                                                │
│         │                                                        │
├─────────┼────────────────────────────────────────────────────────┤
│         ▼                                                        │
│  ┌──────────────────────────────────────────────────────────┐    │
│  │                    plan_thread                             │    │
│  │  target_queue.front() → Planner.plan → Gimbal.send       │    │
│  │                        → Plotter.plot                     │    │
│  │  模式检查: AUTO_AIM → 执行规划                             │    │
│  │            其他模式 → 发送零指令                            │    │
│  └──────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

**关键设计：**
- `target_queue` 容量为 1，`PopWhenFull=true`，始终保留最新目标
- plan_thread 以 10ms（自瞄）/ 50ms（空闲）周期执行
- 主线程退出时设置 `quit=true`，等待 plan_thread join

## 5.4 串口通信协议

### 视觉 → 下位机（VisionToGimbal）

```
字节偏移  大小    字段         说明
──────────────────────────────────────────
0         1      head         固定 0xA5
1         1      mode         0:不控制 1:控制不开火 2:控制+开火
2         4      yaw          float, 目标 yaw (rad)
6         4      yaw_vel      float, yaw 速度前馈 (rad/s)
10        4      yaw_acc      float, yaw 加速度前馈 (rad/s^2)
14        4      pitch        float, 目标 pitch (rad)
18        4      pitch_vel    float, pitch 速度前馈 (rad/s)
22        4      pitch_acc    float, pitch 加速度前馈 (rad/s^2)
26        2      crc16        CRC16 校验和
──────────────────────────────────────────
总计: 28 字节
```

### 下位机 → 视觉（GimbalToVision）

```
字节偏移  大小    字段           说明
──────────────────────────────────────────────
0         1      head           固定 0x5A
1         1      mode           0:idle 1:auto_aim 2:small_buff 3:big_buff
2         16     q[4]           float×4, 四元数 (w,x,y,z)
18        4      yaw            float, 当前 yaw (rad)
22        4      yaw_vel        float, yaw 角速度 (rad/s)
26        4      pitch          float, 当前 pitch (rad)
30        4      pitch_vel      float, pitch 角速度 (rad/s)
34        4      bullet_speed   float, 子弹速度 (m/s)
38        2      bullet_count   uint16, 子弹累计计数
40        2      crc16          CRC16 校验和
──────────────────────────────────────────────
总计: 42 字节
```

## 5.5 ROS2 融合数据流

```
┌──────────────┐   VisionTargetState    ┌──────────────┐
│  sentry.cpp  │ ──────────────────────>│  导航节点     │
│  (视觉)      │   (ROS2 Topic)         │  (Navigation) │
│              │<──────────────────────│              │
└──────────────┘   enemy_status         └──────────────┘
                   autoaim_target
```

**发布内容 (VisionTargetState)：**
```json
{
  "tracking": true,
  "fire_permitted": true,
  "target_id": 3,
  "confidence": 0.95,
  "target_distance": 3.2,
  "target_yaw": 0.15,
  "target_pitch": -0.08,
  "target_position_gimbal": [2.8, 1.2, 0.3],
  "target_position_map": [5.1, 3.2, 0.3],
  "has_target_position_map": true,
  "target_position_map_frame": "map"
}
```

**订阅内容：**
- `enemy_status`: 敌方机器人无敌状态 (vector<int8_t>)
- `autoaim_target`: 指定自瞄目标 (vector<int8_t>)

## 5.6 WebDebugger 数据流

```
┌──────────────┐   HTTP/MJPEG    ┌──────────────┐
│ WebDebugger  │ ──────────────>│  浏览器       │
│ (port 8090)  │                 │  (调试界面)    │
│              │<──────────────│              │
└──────────────┘   参数修改请求   └──────────────┘
       │
       │ runtime_params::apply()
       ▼
┌──────────────┐
│ RuntimeParams│ → version++
└──────────────┘
       │
       │ 各模块 refresh_runtime_params_if_needed()
       ▼
┌──────────────┐
│ Planner 等   │ → 重新加载参数
└──────────────┘
```

**WebDebugger 通道：**
- `/stream/main` — 主画面 MJPEG 流
- `/stream/ballistic` — 弹道画面 MJPEG 流
- `/api/state` — 实时状态 JSON
- `/api/plot` — PlotJuggler 格式曲线数据
- `/api/config` — 参数读取/修改
- `/api/mode` — 模式切换
- 静态资源 — HTML/CSS/JS
